Why assignment-only recovery ignores the stability weight

A caregiver calls in sick. Two recovery policies face the same disruption — the only difference is what each is allowed to move.

A1, assignment-only. Every incumbent visit stays with the caregiver who already had it. Only the orphaned visits are placed. A2, displacement allowed. Incumbent visits may be moved too, to make room.

Both minimise the same objective — 1 × overtime minutes + w4 × assignment changes + 5000 × unserved visits — and deviation is the symmetric difference between the chosen assignment set and the incumbent one, exactly the counting rule the paper uses. Drag w4 and watch which panel moves.

    That is the counting invariant. Under assignment-only recovery, with the incumbent still feasible and every orphaned visit placeable, the set of changed assignments is fixed by the event. Deviation is therefore the same number for every candidate recovery, so w4 × deviation adds the same constant to all of them and cannot reorder anything. The service-maximal efficient set holds exactly one cost vector — several assignment vectors may tie on it, as they do on the left above. A weight cannot create a frontier that the feasible set does not contain. Once displacement is allowed and it strictly lowers attainable overtime at the same service level, at least two non-dominated cost vectors exist, and the weight genuinely selects among them.

    What this page is, and is not

    It is a deliberately tiny instance, solved by exhaustive enumeration in your browser, chosen so the arithmetic can be checked by hand. It is not a result from the paper: no magnitude on this page appears there, and the browser enumerator is not the solver the paper used. It is also not evidence that any implementation is correct — it only shows what the structure implies. The paper's evidence is 518 disruptions nested in 30 derived scenarios from one synthetic base instance, with fixed slots and travel as a workload proxy, no routing and no time-window propagation; on all 488 qualified disruptions A1's efficient set held exactly one cost vector.
