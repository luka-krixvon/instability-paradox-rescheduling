# Paper

The manuscript that accompanies this code is the V1 short paper:

> **The Instability Paradox in Minimum-Disruption Dynamic Rescheduling**
> T.-R. Chen. Preprint (V1), 2026.

- arXiv: *to be added once posted* (primary category: `math.OC`).
- The LaTeX source and compiled PDF are maintained separately in the authors'
  `arxiv_overleaf_package/` (not committed here to keep this repository to code +
  data + results). Add a link to the arXiv abstract page here after posting.

This repository is the **reproducibility companion**: it contains the exact
solvers, the minimal instance data, the released raw results, and the figure
scripts needed to reproduce the paper's three figures and four tables.
